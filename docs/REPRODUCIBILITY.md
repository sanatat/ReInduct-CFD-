# Reproducibility and verification

## Tested environment

In the preparation container, the full numerical suite was rerun with **153 tests passing**, using Python 3.13, NumPy 2.3.5, SciPy 1.17.0, Matplotlib 3.10.8 and pytest 9.0.2. The C++ thermochemical regression uses a C++17 compiler. This is local verification only: the GitHub workflow has not yet been executed on the user account.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
make verify
```

`make verify` executes the active suite across `v4/tests` ... `v13/tests`, compiles a standalone C++17 thermochemistry regression, checks C++/Python numerical agreement, runs a 5 s surrogate case, writes a source-hash evidence manifest and verifies the release metadata. No OpenFOAM command is invoked by this target. The script returns non-zero if a required check fails.

To perform the optional, heavier parameter study:

```bash
make study
```

### Expected artifacts (untracked)

- `v13/results/final_5s/evidence.json`: case metrics, limitations and flags.
- `v13/results/final_5s/fields.npz`: solution state for visualization.
- `v13/results/EVIDENCE_MANIFEST.json`: SHA-256 hashes of active numerical sources, toolchain status, model scope and explicit unsupported verification flags.
- `v13/results/study/`: longer sweep if requested.

**Do not commit output binaries or local run logs as proof of a different user's successful simulation.** Save the automatically generated CI artifact or run the commands on your own computer.

## Current evidence boundaries

The numerical mass and energy residuals are ledger checks for the equations implemented. They are not independent validation. The `v13/openfoam/Allrun` script deliberately exits with an error to prevent an OpenFOAM runtime claim without a v13 solver. Earlier v11 OpenFOAM sources are retained as historical candidates, not as verified v13 OpenFOAM implementations.
