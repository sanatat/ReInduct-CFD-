# راهنمای فارسی ReInduct-CFD Pro v5

## وضعیت واقعی

این نسخه شامل حل عددی دوبعدی میدان الکترومغناطیسی، میدان گرمای القایی مکانی، کوپل واکنش NiO/H2 و انتقال حرارت گاز–جامد، محاسبات ترمودینامیکی، مدل محدود نیروی لورنتس و آزمون داده‌های تجربی منتشرشده است. **۲۳ تست v4+v5 اجرا و موفق شده‌اند**.

**اما OpenFOAM در محیط ساخت پروژه نصب نبود و Docker نیز موجود نبود**. کد حلگر C++ مربوط به OpenFOAM و فایل‌های کیس آماده‌اند و برای تست روی لینوکس و CI اسکریپت داریم، ولی اجرای حقیقی OpenFOAM/کامپایل آن هنوز تأیید نشده است. همچنین هیچ داده آزمایشگاهی از راکتور ساخته‌شده توسط شما در این پروژه وجود ندارد. مدل MHD نیز فقط برای گاز رسانای فرضی است، نه شبیه‌سازی خودسازگار پلاسما.

## دستور اجرا

```bash
sudo apt install g++ make python3 python3-venv python3-pip
cd ReInduct-CFD-Pro-v5
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
make v5all
make v4test
```

برای تست OpenFOAM واقعی ابتدا نصب OpenFOAM v2606 یا Docker را انجام بده، سپس:

```bash
make v5openfoam
```

در صورت وجود Docker، اسکریپت تلاش می‌کند از `microfluidica/openfoam:2606` استفاده کند. اگر کامپایل یا اجرای حلگر خطا دهد، اسکریپت با کد خطا متوقف می‌شود و ادعای موفقیت نمی‌کند. آن تصویر Docker از جامعه توسعه‌دهندگان است.

## دستاوردهای جدید

- مدل MQS دوبعدی در هندسه دو رسانای مستقیمِ متقابل (نه سیم‌پیچ واقعی). خطای جواب تحلیلی با شبکه ۷۲×۵۰ تقریباً ۰٫۰۰۸۲٪ است.
- گرمایش ژولی از میدان الکترومغناطیس محاسبه می‌شود و به معادله دمای جامد منتقل می‌شود. دما نیز رسانایی ماده را تغییر می‌دهد.
- در شبیه‌سازی ۱٫۲ ثانیه‌ای با پارامترهای نماینده، گرمایش القایی بیشینه دمای جامد را حدود ۲۶٫۶ کلوین افزایش داد؛ این عدد پیش‌بینی راکتور واقعی نیست.
- از داده‌های نرخ رشد لایه نیکل در غلظت‌های ۵۳، ۷۵ و ۱۰۰ درصد H₂ مدل ساخته و آن را بر ۲۶ درصد H₂ امتحان کردیم. مدل دو‌رژیمیِ مرتبه اول MAE حدود ۰٫۰۹۱ میکرومتر بر ثانیه دارد. این آزمون داده‌های منتشرشده است، نه تجربه مستقیم آزمایشگاهی.
- مدل جداگانه NiO/H2 با Kp و آنتالپی واکنش وابسته به دما و مراجع NIST/JAEA اضافه شد.
- نیروی لورنتس حرکتی گاز رسانای فرضی به مدل جریان متصل شد، ولی فیزیک خودسازگار پلاسما هنوز وجود ندارد.
- میدان گرمای دوبعدی در قالب فایل `qEM` برای کیس OpenFOAM صادر شده است.

## شکاف‌های واقعی هنوز باز

۱. **کامپایل و اجرای واقعی OpenFOAM v2606** روی یک سیستم که آن را نصب دارد؛ ممکن است C++ حلگر در آن مرحله اصلاح API بخواهد.

۲. **اعتبارسنجی مستقیم راکتور و بازیافت Black Mass** با داده تجربی مستقل و شرایط عملیاتی واقعی. مقایسه داده NiO نرخ سطحی را نشان می‌دهد، نه بازیابی عناصر ارزشمند از باتری.

۳. **مدل کامل پلاسما/MHD** با رسانش الکتریکی محاسبه‌شده، گونه‌های یونیزه، موازنه بار، فیزیک الکترونی و کوپل چندفازی واقعی/حرکت ذرات.

۴. **هندسه واقعی سیم‌پیچ/راکتور، داده خواص مواد، سینتیک مخصوص LiCoO2 و عدم‌قطعیت صنعتی**.
