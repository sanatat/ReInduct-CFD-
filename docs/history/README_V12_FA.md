# راهنمای نسخه ReInduct-CFD Pro v12

## چه چیزی واقعاً اصلاح شد؟

- گاز CO/CO₂/N₂/H₂/H با واحد **مول بر متر مکعب فضای خالی** حمل می‌شود.
- معادله جرم کل گاز در یک مدل یک‌بعدی با فشار تصحیح‌شده ضمنی، قانون گاز ایده‌آل و مقاومت Ergun حل می‌شود. جریان و فشار دیگر فقط ورودی‌های فرضی مستقل نیستند؛ **ولی این روش Navier–Stokes یا PIMPLE کامل نیست**.
- مسیرهای LiCoO₂/C و H₂ ⇌ 2H در یک دستگاه موازنه اتمی مشترک قرار دارند. هیچ واکنش هیدروژنیِ مستقیم با جامد بدون پشتوانه علمی فرض نشده است.
- ورود انرژی الکترونی برای تفکیک محدود H₂، انرژی ذخیره‌شده در رادیکال H و انتقال آن از مرز در موازنه کل انرژی ثبت می‌شود. این یک مدل پلاسما با الکترود/یون/الکترون حل‌شده نیست.
- گرمایش القایی محورمتقارن به صورت ترتیبی با تغییر دمای جامد دوباره محاسبه و محافظه‌کارانه به راکتور نگاشت می‌شود. حلگر EM و CFD هنوز در هر گام زمانی با تکرار کامل حل نمی‌شوند.
- مورد قطعی `fvSchemes` نسخه قبلی اصلاح شد (برای CO، CO₂ و N₂). بررسی ایستا نشان می‌دهد همه جمله‌های جابه‌جایی موجود در کد OpenFOAM، طرح عددی دارند.
- ۱۷ تست جدید اضافه شد و آزمون‌های نسخه‌های v4–v12، در مجموع ۱۴۱ مورد، با موفقیت اجرا شدند؛ یک تست C++17 نیز کامپایل شد و نتیجه درست داد.

## دستورات اجرای واقعی

از پوشه اصلی پروژه:

```bash
sudo apt install python3-venv python3-pip g++ make
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
make v12all
```

برای اجرای مطالعه مستقل کوتاه‌تر:

```bash
python3 -m v12.reactor --duration 5 --output v12/results/base
python3 -m v12.study
```

برای اجرای **آزمایشی** کد OpenFOAM قدیمی پس از نصب و فعال‌سازی OpenFOAM.com v2606:

```bash
make v12openfoam
```

در محیط فعلی دستور آخر با نبود `wmake` و `blockMesh` متوقف می‌شود. ادعای اجرای موفق OpenFOAM **نداریم**.

## نتایج نمونه

نتایج اجرای ۵ ثانیه‌ای، با پارامترهای نمونه و داده سینتیکی که به‌صورت تقریب محلی استفاده شده:

- خطای عناصر و خطای انرژی از فایل `v12/results/base/evidence.json` به صورت قابل‌تکرار ذخیره شده‌اند.
- فشار با تصحیح جرم کل گاز و قانون گاز ایده‌آل تعیین می‌شود.
- نتیجه‌های تبدیل، دما و رادیکال فقط برای همین مدل نمونه معتبر هستند و نباید به‌عنوان بازده عملیاتی واحد بازیافت معرفی شوند.

## هنوز چه چیزی ناقص است؟

۱. OpenFOAM نصب، کامپایل، اجرای کیس و استقلال شبکه روی همان حلگر باید اثبات شود.
۲. فیزیک کامل پلاسمای الکترونی/یونی و MHD به راکتور متصل نشده است.
۳. حرکت مستقل فاز ذرات و کوپل چندناحیه‌ای CFD انجام نشده است.
۴. دما-وابستگی کامل خواص مخلوط، آنتالپی واکنش‌های جامد، سینتیک کالیبره‌شده و ترکیب واقعی Black Mass باقی است.
۵. داده‌های مستقل و قابل‌مقایسه برای اعتبارسنجی کمی خروجی راکتور وجود ندارد. مقاله She و همکاران فقط برای مقایسه کیفی قابل استفاده است، نه معادل‌گرفتن بازیابی، تبدیل و بازده راکتور.

برای وضعیت گام‌به‌گام معیارهای پذیرش، `v12/docs/GAPS_AND_ACCEPTANCE_FA.md` را بخوانید.
