# راهنمای فارسی ReInduct-CFD Pro v4

این پروژه نسخه پیشرفته‌تر v3 است و هیچ‌کدام از نتیجه‌های مصنوعی آن «داده تجربی بازیافت باتری» نیست.

## چه چیزهایی واقعاً اجرا شده‌اند؟

- مدل دوبعدی جریان تراکم‌ناپذیر MAC و انتقال گونه‌ها با حجم محدود و مدل دو دمای گاز و جامد.
- کوپل **دوطرفه محدود**: دمای جامد و مقدار تبدیل روی مقاومت هیدرودینامیکی بستر اثر می‌گذارند و تغییر سرعت گاز روی انتقال و واکنش اثر دارد.
- ماژول میدان مغناطیسی یک‌بعدی و گرمایش ژولی از نسخه قبلی، با بازخورد دمایی.
- آزمون‌های موازنه جرم و انرژی و ۱۰ تست جدید موفق.
- محاسبه استوکیومتری واکنش واقعی مربوط به LiCoO₂ و کربن، با حفظ عناصر.
- مقایسه نرخ رشد لایه نیکل ناشی از کاهش NiO با داده مقاله ۲۰۰۹؛ **مدل آرنیوس ساده در دمای بالا خطای بزرگی دارد**.

**خروجی کیس اصلی:** تبدیل مدل NiO حدود 0.591٪، دمای جامد بیشینه 872.04 کلوین، خطای نسبی موازنه جرم 1.81e-16 و انرژی 1.99e-14. همه برای پارامترهای فرضی هستند.

## اجرای سریع

```bash
sudo apt install g++ make python3 python3-venv
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
make v4all
make v4studies
```

**نکته OpenFOAM:** فایل‌های یک حلگر C++ و کیس دوبعدی داخل `v4/openfoam_v2606` قرار دارند، اما چون OpenFOAM اینجا نصب نبود، هیچ خروجی OpenFOAM ایجاد نشده و کامپایل خود حلگر نیز آزموده نشده است. بعد از نصب OpenCFD v2606 باید با `bash v4/openfoam_v2606/Allrun` کامپایل، `checkMesh` و اجرا را روی سیستم خودت انجام دهی و خطاها را اصلاح کنی.

## محدودیت‌های مهم

- مدل واقعی حرکت ذرات (CFD–DEM/Euler–Euler) وجود ندارد؛ جامد بستر ثابت فرض شده است.
- هندسه واقعی کویل القایی سه‌بعدی و پلاسما حل نشده‌اند؛ فقط مدل میدان یک‌بعدی و بنچمارک جداگانه MHD داریم.
- مدل سینتیکی NiO رآکتور بر اساس پارامترهای نمونه است و داده نرخ رشد مقاله مستقیم قابل تبدیل به نرخ حجمی آن نیست.
- واکنش واقعی LCO/C فقط موازنه استوکیومتری دارد؛ هنوز یک مدل سینتیکی و ترمودینامیکی معتبر LCO ساخته نشده است.
- استقلال کامل شبکه برای دما اثبات نشده است.

بخش `v4/docs/VALIDATION_V4.md` جزئیات عددی، جدول حساسیت و روش استفاده قابل دفاع در رزومه را دارد.
