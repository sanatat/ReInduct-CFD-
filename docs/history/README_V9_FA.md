# ReInduct-CFD Pro v9 | راهنمای فارسی (۶ نوامبر ۲۰۲۶)

هدف این نسخه رفع بخشی از شکاف‌های علمی و فنی نسبت به v8 است؛ هیچ ادعای اجرای واقعی OpenFOAM یا اعتبارسنجی صنعتی بدون شواهد وجود ندارد.

## تغییرات اجراشده

1. ماژول **شیمی H₂/H با حسابداری انرژی** (`v9/plasma_energy.py`): واکنش تجزیه و بازترکیب رادیکال با منبع توان الکترونی مشخص و کنترل موازنه اتم هیدروژن و انرژی. این مدل صفر‌بعدی است و **پلاسما/MHD کامل نیست**.
2. مدل **زمانی LiCoO₂ + C** (`v9/lco_process.py`): محدودیت مقدار کربن، تولید محصول به تفکیک دما، موازنه جرم و عناصر. نرخ‌ها به صورت سناریوی پژوهشی هستند و هنوز با داده مستقل راکتور اعتبارسنجی نشده‌اند.
3. آزمون **چهاربرابری دمای کنارگذاشته‌شده** (`v9/validation_protocol.py`): کیفیت پیش‌بینی روی چهار نقطه تقریبی مقاله بررسی می‌شود؛ این کار اعتبارسنجی مستقل نیست.
4. چارچوب **اعتبارسنجی با داده واقعی** (`v9/external_validation.py`): فقط CSV واقعیِ دارای DOI، شناسه آزمایش، سیستم شیمیایی درست، نسبت کربن، زمان، دما و عدم‌قطعیت پذیرفته می‌شود. فایل قالب در `v9/data/` خالی است؛ نباید با داده ساختگی پر شود.
5. تست اجرای OpenFOAM (`v9/openfoam/Allrun`) و GitHub Actions (`.github/workflows/v9-verification.yml`): چون `wmake` و `blockMesh` در این محیط نیستند، اجرای واقعی هنوز **انجام نشده** است.

## اجرا روی Linux Mint

بعد از بازکردن ZIP، وارد پوشه پروژه شوید:

```bash
sudo apt install python3 python3-venv g++ make
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
make v9all
```

برای اجرای OpenFOAM پس از نصب/فعال‌سازی **OpenFOAM.com v2606**:

```bash
make v9openfoam
```

این دستور باید واقعاً فایل‌های لاگ کامپایل، مش و حلگر را بسازد. اگر خطا داد، در رزومه تجربه اجرای OpenFOAM ذکر نشود.

برای استفاده از داده **واقعی و مستقل** پس از تکمیل فایل CSV قالب:

```bash
python3 -m v9.external_validation --csv path/to/measurements.csv
```

منبع LiCoO₂+C: DOI `10.1007/s11663-022-02712-1`. گزارش اصلی: `v9/docs/SCIENTIFIC_VALIDATION_AND_LIMITATIONS.md`.
