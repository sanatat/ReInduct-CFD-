# ReInduct-CFD — نسخه آماده انتشار در GitHub

این مخزن یک **نمونه‌کار پژوهشی عددی** برای مدل‌سازی واکنش‌های مرتبط با بازیافت مواد باتری است؛ **Digital Twin صنعتی، حلگر کامل CFD یا مدل اعتبارسنجی‌شده آزمایشگاهی نیست**.

## چه چیزهایی واقعاً اجرا و آزمون شده‌اند؟

- مدل کاهش‌یافته یک‌بعدی گاز–جامد با گونه‌های CO، CO₂، N₂، H₂ و H و واکنش‌های نماینده LiCoO₂/C.
- حل تکراری فشار–دما–انتقال گونه‌ها و خواص گرمایی گاز وابسته به دما بر اساس ضرایب Shomate.
- گرمایش القایی محورمتقارن با بازخورد دما در زمان‌های به‌روزرسانی میدان.
- مجموعه ۱۵۳ آزمون عددی و تطبیق محاسبات ترموشیمی Python با یک کد مستقل C++17.

این آزمون‌ها صرفاً **درستی عددی بخش‌های پیاده‌سازی‌شده** را بررسی می‌کنند. حلگر OpenFOAM نسخه ۱۳ اجرا نشده و مدل کامل پلاسما/MHD یا اعتبارسنجی مستقل راکتور نداریم.

## اجرا روی Linux Mint / Ubuntu

```bash
sudo apt install python3-venv python3-pip make g++
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
make verify
```

مطالعه حساسیت پارامترها: `make study`.

پس از اجرا، گزارش عددی داخل `v13/results/EVIDENCE_MANIFEST.json` تولید می‌شود. پوشه نتایج جدید از GitHub کنار گذاشته شده است تا مخزن سبک بماند؛ نمودارها و نمونه خروجی داخل `docs/` حفظ شده‌اند.

برای جزئیات علمی، [README انگلیسی](README.md)، [روش بازتولید](docs/REPRODUCIBILITY.md) و [محدودیت‌ها](docs/SCIENTIFIC_LIMITATIONS.md) را بخوانید.

## انتشار در GitHub

این مخزن شامل `.gitignore`، مجوز MIT، یک workflow آزمون خودکار و فایل راهنمای مشارکت است. **تأیید سبز GitHub Actions تنها پس از اجرای موفق روی حساب GitHub شما معتبر خواهد بود**. وضعیت OpenFOAM را در CV یا توضیحات مخزن، تکمیل‌شده معرفی نکنید.
