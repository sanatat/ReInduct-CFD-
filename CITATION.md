# Citing this repository

There is no assigned project DOI or peer-reviewed publication associated with the repository. Do not invent one. Once the public GitHub repository exists, cite its **actual** URL and a specific commit SHA or GitHub release tag, for example:

> ReInduct-CFD contributors (2026). *ReInduct-CFD: reactive battery-recycling numerical research prototype*, GitHub, version v13.1, commit `<actual SHA>`, `<actual repository URL>`.

Before external publication, confirm the repository owner's preferred author/contributor name and whether a public archive DOI has been created. The published scientific papers and NIST coefficients used as references must be cited independently.
